Grimmory / BookLore

AO3's own EPUB export puts everything — rating, category, warnings, fandoms, relationships, characters and every freeform tag — into one flat subject list, because EPUB has no separate tag field. Grimmory reads that list as Genres, so an untouched file lands with fifty genres and no tags.
